# Pinecone 更新说明（2026-11-02）

> 本次更新聚焦三件事：让工作区**自己定义字段**，让工作项**有明确的交付时限**，
> 让列表**能按条件筛选并记住常用视角**。
> 涉及数据库结构变更，升级前请先阅读文末「升级步骤」。

---

## 一、本次更新的核心变化

| 能力 | 此前 | 现在 |
|---|---|---|
| 扩展字段 | 客户要加一个「影响版本」字段，只能改表改代码 | 工作区管理员在设置页自助新增，即时生效 |
| 交付时限 | 只有迭代与发布有计划日期，单个工作项没有承诺日 | 任务 / 功能 / 支持请求可单独设承诺完成日，并自动标出风险 |
| 逾期可见性 | 只能逐个点开详情页查看 | 列表与看板卡片直接标出已逾期与高风险的条目 |
| 筛选 | 只能按单一状态过滤，且只在当前页内生效 | 状态/优先级/负责人/自定义属性多条件叠加，服务端筛选覆盖全部数据 |
| 常用视角 | 每次都要重新调筛选条件 | 筛选与列配置可存为视图，个人或共享，一键切换 |
| 数据进出 | 自定义字段无法批量导入导出 | 导入模板与映射向导支持自定义属性，导出按列配置自动带上 |

---

## 二、新增：工作区自定义属性

### 能做什么

为需求、功能、任务、支持请求四类实体扩展字段，全程无需改动代码：

- **七种字段类型**：文本、数字、单选、多选、日期、勾选、链接
- **必填控制**：标记为必填的字段，创建或更新时缺失会被拦下并给出明确提示
- **排序**：配置面板可上下调整展示顺序，详情页与表单按同一顺序呈现
- **归档**：不再使用的字段可归档，历史值保留、界面不再展示，随时可恢复
- **删除**：彻底移除字段定义，同时清除各实体中对应的历史值

### 使用路径

1. 进入 **设置 → 自定义属性**，选择实体类型
2. 新建字段：填写展示名与字段标识，选择类型；单选/多选需配置选项
3. 在实体详情页的「自定义属性」区域填写与修改
4. 新建实体时，字段收在「更多属性」折叠区里

### 需要注意的规则

- **配额默认 20 个**：单个工作区、单类实体最多 20 个启用中的字段，可由部署环境变量 `CUSTOM_FIELD_LIMIT` 调整（上限 200）。达到上限时新建按钮会禁用并提示先归档；归档不占额度，所以不会被锁死
- **字段标识不可改**：保存后标识（如 `affect_version`）锁定，因为它是值存储的定位依据；展示名随时可改
- **类型变更受限**：已有数据的字段只允许在「文本」与「链接」之间切换，其他类型变更需要新建字段替代，避免历史值失真
- **日期字段不参与逾期计算**：自定义的日期字段只是业务属性。若要驱动逾期与风险，请使用系统内置的「交付时限」

## 三、新增：交付时限与风险标识

### 承诺完成日

任务、功能、支持请求的详情页新增「交付时限」一行，可直接选择日期。需求池不设该字段——尚未进入交付阶段的需求不需要承诺日。

### 风险如何判定

有效截止日按以下顺序取第一个有值的：

```
工作项承诺完成日 → 所属迭代结束日 → 所属发布结束日
```

回退只影响展示，不会把推算出来的日期写回工作项。当日期来自迭代或发布时，界面会明确标注来源。

判定规则：

| 状态 | 条件 | 展示 |
|---|---|---|
| 已完成 | 处于该实体的完成态 | 不显示标识 |
| 已逾期 | 已过有效截止日 | 红色标识 + 逾期天数 |
| 风险较高 | 时间消耗达 85% | 红色「风险较高」 |
| 接近截止 | 时间消耗达 60% | 黄色 |
| 正常 | 时间消耗低于 60% | 绿色 |

时间消耗按日历日计算，不做时区换算，避免跨时区出现差一天。

### 在哪里能看到

- **详情页**：日期 + 风险标识 + 回退来源说明
- **任务看板 / 泳道 / 列表**：卡片或行标题后标出「已逾期」「风险较高」
- **功能 / 支持请求的列表与看板**：同上

列表上**只标逾期与高风险两类**，正常与接近截止不标——如果每条都染色，颜色就失去了提示作用。

## 四、改进

- **新建表单支持扩展字段**：四类实体的新建入口都可填写自定义属性与承诺完成日。存在必填字段时折叠区默认展开，避免用户看不见必填项、提交后才报错
- **创建失败的提示更明确**：此前部分新建表单校验失败时没有反馈，用户误以为没点上。现在会显示服务端返回的具体原因，如「「影响版本」为必填项」
- **支持请求新建补齐发布周期**：此前新建支持请求无法选择所属发布，导致交付时限的发布回退对支持请求始终无效。现已补上
- **字段定义的读取做了缓存**：详情页与新建表单共用同一份字段定义，不重复请求；在配置面板改完当前实体类型的字段后会主动刷新，无需手动重载页面

## 五、新增：筛选与保存视图

### 按条件筛选

四类实体的清单视图都接入统一的筛选面板，支持**状态、优先级、负责人、自定义属性（单选类型）**四类条件，可多选叠加。

与以往不同的是，筛选在**服务端**执行：结果覆盖全部数据，而不是只在当前已加载的一页里过滤。这也是本次把原有的状态下拉一并迁过来的原因——两套过滤并存会出现「筛了但没筛全」的错觉。

顺带修掉一个隐藏问题：清单视图原先只在前端过滤，翻页后筛选结果不完整；现在分页与筛选语义一致。

### 保存视图

筛选条件与列配置可保存为视图，下次一键切换：

| 能力 | 说明 |
|---|---|
| 保存 | 输入视图名即可保存当前筛选与列配置 |
| 共享 | 勾选后工作区成员都能看到；不勾选则为个人视图 |
| 更新 | 视图创建者可覆盖保存当前条件 |
| 删除 | 仅创建者可删除 |
| 唯一性 | 同一实体类型下视图名不可重复 |

权限上刻意没有做「管理员可改他人视图」——视图是个人工作习惯，被他人改动比看不到更难受。

## 六、新增：列表列配置（任务清单）

任务清单视图新增「列」按钮，可勾选要显示的**自定义属性列**。选中后：

- 表格在创建时间之后追加对应列
- 导出（CSV / xlsx / PDF）同步带上这些列
- 列配置随保存视图一起记忆

单选/多选显示选项名称，勾选显示 ✓ / —，日期截取到日。

内置列（编号、状态、优先级等）暂不支持增删：做成完全动态的列渲染会与勾选导出、列宽、空态多处耦合，收益不抵风险，留待后续统一。

## 七、新增：导入导出的自定义属性支持

### 导入

- 映射向导的目标字段下拉现在包含该工作区**启用中的自定义属性**，标识为 `cf:<字段标识>`
- 下载的 Excel 模板同步追加这些列：表头显示中文名，单选字段带下拉验证，示例行留空
- 取值规则：多选按 `,` `;` `|` 拆分，勾选接受「是 / true / 1 / y / yes」，其余按文本；非法值只影响该行，不中断整批
- 导入不强制自定义属性的必填：避免一批历史数据因缺字段整批失败，缺项留给后续编辑时补
- 支持范围限于需求与支持请求（测试用例没有自定义属性值列）

### 导出

导出按列表当前的列配置生成，**选中的自定义属性列会自动出现在导出文件里**，无需额外配置。

## 八、数据库变更

新增迁移 `20261102140000_add_entity_due_dates`：

```sql
ALTER TABLE "stories"  ADD COLUMN IF NOT EXISTS "due_date" DATE;
ALTER TABLE "features" ADD COLUMN IF NOT EXISTS "due_date" DATE;
ALTER TABLE "supports" ADD COLUMN IF NOT EXISTS "due_date" DATE;
```

同时建立 `(workspaceId, due_date)` 索引，供逾期清单与风险视图过滤。

自定义属性的表结构与四张实体的值列此前已就绪（迁移 `20261102120000_add_custom_fields`），本次补齐的是读写链路与界面，**不重复建表**。

新增迁移 `20261102160000_add_saved_views`，建立保存视图表：

```sql
CREATE TABLE "saved_views" (
  id, workspaceId, entityType, name,
  filters JSONB NOT NULL,
  columns JSONB,
  isShared BOOLEAN NOT NULL DEFAULT false,
  createdById, sortOrder, createdAt, updatedAt
);
```

按自定义属性值筛选所需的 GIN 索引仍未建立。当前筛选走的是 JSONB 路径等值比较，而 GIN 的 `jsonb_path_ops` 只对包含查询有效，建了也用不上，反而增加每次写入的开销。等筛选扩展到多选/文本类型时再随迁移一并添加。

## 九、升级步骤

```bash
# 1. 拉取代码后更新依赖
pnpm install

# 2. 应用数据库迁移
pnpm --filter backend exec prisma migrate deploy

# 3. 重新生成 Prisma 客户端
pnpm --filter backend exec prisma generate

# 4. 构建
pnpm build
```

升级后建议按以下顺序自检：

1. 设置页出现「自定义属性」页签，配额显示为 `已用 0 / N`（N 为当前生效上限，默认 20）
2. 建一个文本类型必填字段，尝试在任务详情页留空保存，应看到必填提示
3. 给任务设置承诺完成日，确认详情页出现风险标识
4. 同一任务不填承诺日、但挂到有结束日的迭代上，确认标识按迭代结束日计算并标注来源
5. 把承诺完成日改到昨天，确认列表行出现「已逾期」标记
6. 建一个单选类型字段并在任务上填值，回到清单视图用「筛选」按该值过滤，确认只返回匹配数据
7. 把当前筛选与列保存为视图，刷新页面后从视图下拉切回，确认条件与列配置被还原
8. 下载导入模板，确认自定义属性列已出现；按模板填一行导入，确认字段值落到实体的自定义属性里

## 十、已知限制

- **风险不随时间自动刷新**：页面长时间开着不会跨零点自动变色，切换页面或刷新后生效。刻意没有引入定时器，避免后台页面持续重算
- **自定义属性筛选仅支持单选类型**：文本、数字、日期的精确匹配意义有限，多选字段的「包含」查询需要换一种索引与查询方式，留待后续
- **列配置仅覆盖任务清单的自定义属性列**：内置列暂不支持增删，其他三张列表页仍为固定列
- **导入的自定义属性不做必填强制**：缺项需在后续编辑时补，不会在导入阶段报错
- **视图不保存排序与分组**：保存的是筛选条件与列配置
- **删除字段不可恢复**：归档是可逆的，删除不是——删除会一并清除历史值
