## 1. 系统简介

Pinecone 是一套面向产品研发团队的轻量级项目管理系统，覆盖从**需求收集 → 功能规划 → 任务执行 → 发布交付 → 工时统计 → 知识沉淀**的全流程。系统提供**清单 / 按状态 / 按发布周期 / 按负责人**多种视图，支持拖拽流转、一键导出，并内置知识库用于团队文档沉淀。

### 1.1 核心概念

| 概念 | 说明 |
| --- | --- |
| **工作区（Workspace）** | 数据隔离的基本单位，通常对应一个项目/团队；不同工作区之间数据互不可见 |
| **需求（Idea）** | 产品需求的初始形态，来源于用户反馈、内部创意等，可升级为功能 |
| **功能（Feature）** | 经过评估后正式立项的功能点，隶属于某个发布周期 |
| **任务（Story）** | 功能拆分后的具体执行单元，可分配负责人、估算工时 |
| **发布周期（Release）** | 版本迭代的时间箱，功能/任务按发布周期组织，可设置产能上限 |
| **支持请求（Support）** | 用户反馈与缺陷记录，可转需求、转功能、转任务 |
| **知识库（KB）** | 团队 Wiki，按空间组织页面，支持富文本编辑与权限可见性 |

### 1.2 页面导航

登录后进入左侧边栏导航，包含功能入口：

| 导航项 | 路径 | 说明 |
| --- | --- | --- |
| 概览 | `/` | 统计卡片、工作区管理、最近活动、AI 摘要 |
| 支持请求 | `/supports` | 用户反馈与缺陷管理 |
| 需求池 | `/ideas` | 需求收集与评估 |
| 功能列表 | `/features` | 功能规划与发布周期编排 |
| 任务看板 | `/stories` | 任务执行看板 |
| 发布计划 | `/releases` | 版本周期管理（列表 ⇄ 甘特图） |
| 工时 | `/time-tracking` | 工时记录与统计 |
| 导入 | `/imports` | CSV 批量导入 |
| 回收站 | `/trash` | 已删除实体恢复 |
| 设置 | `/settings` | 成员管理、注册访问控制、Webhook（管理员） |
| 知识库 | `/kb` | 团队文档（新窗口打开） |

> 提示：右上角可切换**简体中文 / English** 界面语言，选择后全局生效；侧边栏底部可退出登录。

## 2. 快速开始

### 2.1 注册账号

1. 打开登录页，点击「还没有账号？去注册」。
2. 填写**姓名、邮箱、密码**（密码至少 6 位），再次确认密码。
3. 点击「注册」，注册成功后自动登录进入系统。

> **注册模式**：系统管理员可设置注册模式（开放 / 白名单 / 邀请码）：开放=任何人可注册；白名单=仅白名单邮箱可注册；邀请码=需有效邀请码。若注册被拒（提示"注册受限"），请联系管理员。

### 2.2 登录与 SSO

- **账号登录**：输入注册邮箱与密码，点击「登录」。会话访问令牌 60 分钟自动刷新（无感），刷新页面不掉线。
- **企业账号（SSO）登录**：若企业已配置 SSO（OIDC 或 SAML 2.0），登录页底部显示「企业账号登录」入口，跳转 IdP 认证后自动回跳并登录；首次 SSO 登录自动建号并入工作区。

### 2.3 忘记密码

登录页点击「忘记密码？」→ 输入注册邮箱 → 系统发送**一次性重置链接**（30 分钟有效、仅用一次）到注册邮箱；点击邮件中的「重置密码」设置新密码。重置成功后**所有已登录会话被强制下线**。

### 2.4 首次使用三步走

1. **创建工作区**：首次登录若无工作区，首页引导创建第一个工作区。
2. **创建发布周期**：在「发布计划」页创建首个版本周期，规划起止时间与产能。
3. **录入第一张卡片**：按"需求 → 功能 → 任务"链路录入，或从「支持请求」录入用户反馈。

## 3. 工作区与设置

### 3.1 创建 / 切换工作区

- 首次引导：首页直接显示创建表单，填写**名称**（必填）与**标识**（可选，仅小写字母/数字/连字符）。
- 再次创建：点击侧边栏顶部工作区名称下拉中的「创建工作区」。
- 切换：点击侧边栏顶部工作区名称，在下拉列表点击目标工作区（当前带 ✓）。

### 3.2 设置页（下划线页签）

| 页签 | 内容 | 可见范围 |
| --- | --- | --- |
| **成员管理** | 邀请成员 + 成员列表（调整角色 / 移除） | 全部成员 |
| **注册访问控制** | 邮箱白名单 + 邀请码 + 用户禁用 | 仅系统管理员 |
| **企业登录** | 企业身份源（OIDC · SAML）+ SCIM 预配 | 仅工作区管理员 |
| **Webhook** | 出站事件端点管理 | 仅工作区管理员 |
| **系统管理** | 操作审计查询与导出 | 仅系统管理员 |

**成员管理**：邀请成员（邮箱 + 角色：管理员/成员/只读）；成员列表支持搜索、调角色、移除（**唯一管理员不可被移除**）。

### 3.3 注册访问控制（系统管理员）

- **邮箱白名单**：白名单模式下仅这些邮箱可注册。
- **邀请码**：生成邀请码（自定义或自动、设最大使用次数/过期时间），支持复制、停用/启用、删除。
- **用户管理**：禁用/启用任意账号——被禁用用户立即无法登录，现有会话失效。
- 请勿禁用自己的账号（系统会拦截）。

## 4. 概览首页

登录后进入"驾驶舱"：

- **欢迎信息 + 本周动态**：显示「本周新建 N 项」徽章（4 类实体新增总数）。
- **6 张统计卡片**：支持 → 需求 → 功能 → 任务 → 工时 → 发布；前 5 张显示"进行中 / 总数"，工时卡片显示本月工时合计；点击卡片直达对应页。
- **最近活动**：最近 10 条跨实体操作记录（含操作人、编号、标题、时间）。
- **AI 摘要**：右上角「AI 摘要」一键生成工作区概况（未配置 AI 时自动模板摘要）。

> "进行中"指未完成/未关闭状态集合。

## 5. 支持请求

集中管理**用户支持请求**与**缺陷（Bug）**，可转化为正式需求、功能或任务。

### 5.1 新建请求

进入「支持请求」页 → 右上角「新建请求」→ 填写**标题**（必填）、**描述**（选填）、选择**类型**：`支持请求`（紫色）/ `缺陷`（红色）。缺陷可一并设置**严重度**（致命/严重/一般/轻微）与**根因**（选填）。

### 5.2 三种视图

| 视图 | 说明 | 交互 |
| --- | --- | --- |
| **清单** | 表格，勾选行、筛选、导出 | 点击行进详情 |
| **按状态** | 看板（待处理 / 评审中 / 已完成） | 拖拽卡片变更状态 |
| **按负责人** | 按负责人分组 | 拖拽改/清空负责人 |

### 5.3 详情页（5 个页签）

详情 / 评论 / 历史 / 关联 / 工时。评论、关联页签显示数量角标。详情页支持编辑字段、变更状态与类型、设负责人、加标签、上传附件、类型=缺陷时设严重度与根因、克隆为需求/功能/任务。

### 5.4 转需求 / 转功能 / 转任务

详情页「操作」区点击对应按钮，系统创建同名实体并建立"升级自/克隆自"关联。若来源为 `缺陷`，**转任务**自动将新任务标 `kind=DEFECT`（红色「缺陷」徽标）；技术债任务可手动标 `CHORE`（灰色徽标）。

## 6. 需求池

### 6.1 新建 / 视图

进入「需求池」→「新建需求」→ 填标题（必填）、描述、分类标签。三种视图：清单 / 按状态（8 态看板）/ 按负责人，均支持拖拽。

### 6.2 升级为功能

需求详情页点击「升级」，选优先级（P0~P3），生成对应 Feature 并保留"升级自"关联。

### 6.3 任务清单（TO-DO）

需求详情页「TO-DO 清单」页签：新建 TO-DO（标题/描述/负责人/要求完成日期）；完成勾选记录实际完成时间；逾期显示红色标记；仅创建人或负责人可编辑，仅创建人可删除。

## 7. 功能列表

### 7.1 新建功能

「功能列表」→「新建功能」→ 填标题（必填）、描述、所属**发布周期**、**优先级**（P1 最高 / P2 高 / P3 中（默认）/ P4 低 / P5 最低）。

### 7.2 四种视图

清单 / 按状态（待处理/待梳理/拆分中/开发中/验证中/已关闭）/ **按发布周期**（以"未分配+各发布"为列的看板，拖拽分配，顶部显示产能进度条：<80%绿 / 80~99%黄 / ≥100%红）/ 按负责人。

产能计算：功能工作量（小时）÷ 8 = 人天；按天计累加。

### 7.3 功能详情

5 页签；支持编辑、变更状态/优先级/负责人/发布、设工作量（小时/天）、加标签、传附件、**克隆为任务**（自动继承发布周期）。

## 8. 任务看板

### 8.1 创建任务

- 直接新建：「任务看板」→「新建任务」→ 所属功能（必选）+ 标题（必填）+ 描述。
- 从功能创建：功能详情页「克隆为任务」，一键生成继承发布的任务。

### 8.2 状态与视图

状态：`待办 → 进行中 → 评审中 → 已完成`，另有 `阻塞`。四种视图：清单 / 按状态（拖拽改状态）/ 按发布周期（只读）/ 按负责人（拖拽改/清空负责人）。

### 8.3 任务详情与子类型

5 页签；支持验收标准、预估工时、所属功能/发布、标签、附件、记录工时、测试。子类型徽标：普通无标记；缺陷克隆任务红色「缺陷」；技术债灰色「技术债」。

### 8.4 任务测试（用例验证）

任务详情「测试」页签是**任务级验证闭环**：用例列表、新建用例（自动关联任务）、标记 `PASS/FAIL/BLOCKED`（计入发布回归进度）、点击编号跳用例详情。用例双视角挂载（Story 主链接 + Release 回归归属）。

## 9. 发布计划

### 9.1 新建 / 状态

「发布计划」→「新建发布」→ 名称（必填）、版本号、起止日期、Stage/Prod 日期、总产能（人天）。状态：`未开始 → 执行中 → 已关闭`（已关闭不可编辑、不出现在看板发布列）。

### 9.2 甘特图

发布计划页右上角切换 **列表 ⇄ 甘特图**：时间轴月刻度、状态色条、里程碑菱形（灰=灰度 / 绿=上线）；未关闭发布可拖主体平移、拖边缘拉伸、拖菱形改里程碑日期，松手自动保存；未排期/已关闭不支持拖拽。

### 9.3 测试进度 / 测试计划 / CI 导入

- **测试进度**（发布详情）：通过率进度条 + 用例清单 + 标记执行 + 失败一键建缺陷；发布已关闭后禁用。
- **测试计划 TestPlan**：命名批次（DRAFT→ACTIVE→COMPLETED/ARCHIVED），拉入发布用例，自动汇总通过率。
- **导入 CI 结果（JUnit）**：发布详情「导入 CI 结果」选 JUnit XML → 匹配/新建用例 → 生成执行记录 → 导入报告。
- **测试单 + 手动走查**：侧边栏「测试单」(`/test-plans`)，用例库跨发布模板；「启动走查」派生走查批次进入走查页连续执行（`/test-plans/[id]/walkthrough`）。

### 9.4 公开发布分享（NARRATIVE）

发布可生成**分享令牌**对外展示：叙事化路线图（按状态分组 + 里程碑 + 多发布聚合）+ 品牌化标题/配色；投票人状态变更收到站内+邮件通知。

## 10. 工时跟踪

「工时」页 →「记录工时」→ 选关联**任务**、填**工时数**（0.5 步进）、日期、工作描述（选填）。顶部实时显示总工时；可计费记录带标记；悬停可删。

工时也可从任务/功能/需求/支持详情页「工时」页签直接记录。

## 11. 知识库

团队 Wiki，按"空间 → 页面"两级组织，新窗口打开 `/kb`。

- **新建页面**：页面树「+ 新建页面」；可「从模板创建」（标题与正文自动填充）。
- **子页面 / 设为模板 / 移动页面**：支持树形结构、模板复用、移动到其他父页面（防循环保护，不能移到自身/子孙下）。
- **页面操作**：评论、附件（悬停删）、标签、可见性（所有人/成员/管理员）。
- 富文本支持标题层级、加粗/斜体/下划线、列表、任务列表、表格、链接、图片、色块、单元格合并等。

## 12. 通用操作与技巧

- **看板卡片统一风格**：编号 + 状态/优先级/类型徽标（删除按钮悬停显示）/ 标题 / 标签 + 负责人；点击卡片新标签页打开详情。
- **清单勾选**：行首复选框勾单行，表头全选/取消（作用于当前筛选）。
- **导出数据**：清单模式「下载」→ CSV / Excel(.xlsx) / PDF；先勾选再导出只导出勾选行。
- **拖拽规则**：按状态=改状态；按发布（功能）=分配发布；按负责人=改/清空负责人；按发布（任务）只读。
- **详情页页签**：详情 / 评论 / 历史（发布变更显示名称）/ 关联（显示编号+方向）/ 工时 / TO-DO（仅需求）。
- **语言切换**：侧边栏底部切换中文/English，即时生效全局记忆。
- **页签数量角标**：评论/关联页签显示绿色数字角标，为 0 时隐藏，实时更新。
- **退出登录**：侧边栏底部退出图标，返回登录页并清除服务端会话。

## 13. 开放平台与集成

### 13.1 Webhook

「设置 → Webhook」新建端点：填名称 + 接收 URL + 订阅事件（或 `*` 全部）；创建后**仅显示一次 Secret**；事件发生时异步投递，请求头含 `X-Pinecone-Signature`（HMAC-SHA256）、`X-Pinecone-Event-Id`、`X-Pinecone-Timestamp`（防重放）；失败可在端点详情查看历史并手动重发。

### 13.2 CSV 批量导入

「导入」页选实体类型 → 下载示例模板 → 上传 UTF-8 CSV；系统自动值映射（如"Bug"→缺陷）、引用解析（邮箱→负责人、版本号→发布）、注入清洗；预览后执行，显示逐行结果报告。

### 13.3 企业登录（SSO：OIDC · SAML）

「设置 → 企业登录」创建身份源：
- **OIDC**：填名称、Issuer、Client ID、Client Secret、Scopes + 域名白名单；首次登录自动建号入工作区（JIT）。
- **SAML 2.0**：填名称、SP Entity ID、粘贴 IdP 元数据 XML；界面显示 ACS 消费地址与 SP 元数据导出地址填入 IdP。
- Client Secret 仅创建时显示一次。详细见《企业 SSO 对接指南》。

### 13.4 SCIM 2.0 预配

「企业登录 → SCIM 2.0」生成/重置 Token（仅显示一次）；复制 SCIM 端点（`/api/workspaces/<wsId>/scim/v2`）与 Token 配置到 IdP；组名以 `-ADMIN/-MEMBER/-VIEWER` 结尾（或精确映射）自动获得对应角色。

### 13.5 通用 CI 结果回写

「设置 → Webhook/CI 配置」配置 GitHub/GitLab/Gitee 源与签名密钥/API Token；CI 调用 `POST /ci/results`（HMAC 或 Bearer 双通道认证）上报 JUnit 结果；commit/PR 关联自动回链到实体。

**HMAC 签名**：载荷为 `${timestamp}.${rawBody}`，其中 `timestamp` 为 **`X-Pinecone-Timestamp`** 请求头值（毫秒时间戳，**±5 分钟窗口**）。每次请求必须携带 `X-Pinecone-Timestamp` 头（毫秒时间戳）；服务端拒绝缺失或超出 ±5 分钟窗口的请求。

## 14. 治理与安全

- **系统管理员与审计**：`isSystemAdmin` 登录后见「系统管理」页签，按时间/用户/操作类型筛选审计并可导出 CSV（UTF-8 BOM）。
- **回收站**：侧边栏「回收站」集中软删除实体，点「恢复」还原（关联一并恢复）。
- **数据备份**：加密备份（pg_dump → AES-256-GCM），保留策略见 `scripts/backup-db.js` 与 `scripts/decrypt-backup.js`；建议异机存放并定期验证恢复。

## 15. 智能化功能

### 15.1 AI 摘要（BYO Endpoint）

概览首页/发布详情「AI 摘要」生成概况；未配置 AI 时模板摘要（界面标注来源）。配置 3 个后端环境变量：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `AI_API_KEY` | ✅ | 启用开关，不配置=模板摘要 |
| `AI_BASE_URL` | 可选 | OpenAI 兼容网关，默认官方，`/v1` 结尾 |
| `AI_MODEL` | 可选 | 默认 `gpt-4o-mini` |

支持官方 OpenAI、企业网关、内网 Ollama（Key 任意非空，base 指向 `:11434/v1`）。配置后重启后端生效。

### 15.2 PWA 离线与安装

自动注册 Service Worker 缓存核心页面；断网可开已访问页；浏览器「安装应用」可装为桌面/手机应用；更新后刷新自动切最新缓存。

## 16. 产品发现层（反馈门户 / 投票 / 主题 / 评分）

### 16.1 客户反馈门户

工作区设置 → 反馈门户：开启后生成**门户令牌**（URL `/feedback/:token`）；设提交落点（支持请求/需求）；可选强制邮箱校验。将链接发给客户，客户免登录提交反馈/投票；提交带 `portal` 标签；令牌维度限速防刷票。

### 16.2 投票（Vote）

Idea / Support / Feature 可投票计票：内部列表/详情一键投票（卡片显示票数徽章）；门户客户投票；唯一约束防重复（内部按用户、门户按邮箱）。

### 16.3 主题聚合（Theme）

「主题」页(`/themes`)新建主题 → 关联相关反馈 → 主题卡聚合票数与关联数 → 高票主题「提升为特性」一键建 Feature 并写关联。

### 16.4 优先级评分（RICE / ICE / CUSTOM）

工作区设置 → 评分（仅管理员）选默认模型与权重。公式：RICE=`(Reach×Impact×Confidence)/Effort`；ICE=`Impact×Confidence×Ease`；CUSTOM=`Σ(维度值×权重)` 归一化 0–100。**关键闭环**：RICE 未手动填 Reach 时**默认取该条投票数**作为 Reach，民主直接驱动排序。列表支持按评分/票数排序、按主题/最低分筛选。

## 17. 常见问题 FAQ

**Q2：按发布周期看板看不到已关闭发布？** 已关闭发布不再参与排期，从历史数据仍可在「发布计划」查看。

**Q3：功能/任务无法拖拽？** 功能在按状态/发布/负责人视图可拖拽；任务在按状态/负责人视图可拖拽，按发布周期视图只读；请确认视图模式。

**Q4：拖到"未分配"列负责人没变？** 拖到未分配=清空负责人（前提是原本有负责人）；原本无负责人则不触发。

**Q5：统计卡片 `2 / 5` 含义？** "进行中数量 / 总数"。

**Q6：发布红色产能进度条？** 已用产能 ≥ 100%，建议调整分配或提升总产能。

**Q7：如何改任务所属功能？** 任务详情「所属功能」调整，或功能详情重新克隆。

**Q8：删除能恢复吗？** 软删除进回收站可恢复；知识库附件删除会同时清磁盘文件。

**Q9：忘记密码？** 登录页「忘记密码？」→ 邮箱 → 一次性链接（30 分钟/单次）→ 重置；成功后所有会话下线。

**Q10：知识库为何新窗口打开？** 独立布局隔离编辑体验，关闭后可从侧边栏重进。

**Q11：长时间停留会被踢下线？** 不会，令牌 60 分钟无感刷新。

**Q12：注册提示"注册受限"？** 白名单/邀请码模式，联系管理员加白名单或发邀请码。

**Q13：TO-DO 无法勾选完成？** 仅创建人或负责人可操作；删除仅创建人。

**Q14：模板选不到？** 需先在页面操作栏「设为模板」才会出现在下拉。

**Q15：移动页面提示不能移到自身/子孙下？** 防循环保护，请选其他父页面或根级。

**Q16：邮箱大小写写错能登录？** 系统统一小写存储匹配，任意大小写均可。

**Q17：收不到重置邮件？** 查垃圾箱；每次发送旧链接失效，用最新一封；仍未收到联系管理员确认 SMTP。

**Q18：甘特图拖不动？** 未排期或已关闭发布不支持拖拽，请先设起止日期。

**Q19：导入 CI 结果"解析 0 条"？** 确认标准 JUnit XML（含 `<testcase>` 节点）。
